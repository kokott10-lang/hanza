# 한자 500 (안드로이드 앱)

5급 배정한자 500자 암기카드를 안드로이드 앱(APK)으로 만드는 프로젝트입니다.
GitHub에 올리면 APK가 자동으로 만들어집니다. 컴퓨터에 안드로이드 개발 도구를 설치할 필요가 없습니다.

## 1. GitHub에 올리기

1. GitHub에서 새 저장소(Repository)를 만듭니다. 이름은 자유(예: `hanja500`), **Public** 권장.
   (Private도 되지만, 휴대폰에서 APK를 바로 받으려면 Public이 편합니다.)
2. 새 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
3. 이 폴더 안의 내용 전체를 끌어다 놓습니다.
   - 반드시 포함: `www/`, `assets/`, `.github/`, `package.json`, `capacitor.config.json`, `.gitignore`
   - `.github` 폴더는 점(.)으로 시작해서 파일 탐색기에서 숨겨져 있을 수 있어요. 숨김 파일 표시를 켜 주세요.
4. **Commit changes**를 누릅니다.

## 2. APK 만들어지길 기다리기

1. 저장소의 **Actions** 탭을 엽니다. "Build Android APK"가 자동으로 실행됩니다. (5~10분)
2. 초록 체크가 뜨면 완료입니다. 빨간 X면 실행 로그를 눌러 오류 내용을 알려 주세요.
3. 자동 실행이 안 되면 Actions 탭 → Build Android APK → **Run workflow**를 누릅니다.

## 3. 휴대폰에 설치하기

1. 휴대폰 크롬에서 저장소 오른쪽 **Releases → 한자 500 APK (최신)** 로 들어가 `hanja500.apk`를 받습니다.
   - Private 저장소라면 Actions 실행 화면 아래 Artifacts의 `hanja500-apk`(zip)를 컴퓨터에서 받아 apk를 휴대폰으로 옮기세요.
2. 받은 파일을 열면 "출처를 알 수 없는 앱" 허용 안내가 뜹니다. 허용하고 설치합니다.
3. Play 프로텍트 경고가 나오면 **그래도 설치**를 선택합니다. 직접 만든 앱이라 나오는 경고입니다.

## 삭제하기

일반 앱과 같습니다. 앱 아이콘을 길게 눌러 **삭제**하거나 설정 → 앱 → 한자 500 → 제거.
앱을 지우면 앱 안의 학습 기록도 함께 지워집니다.

## 참고

- 학습 기록은 그 휴대폰 안에만 저장됩니다.
- 앱 내용을 바꾸려면 `www/index.html`을 수정해 다시 올리면 APK가 새로 만들어집니다.
- 이 APK는 디버그 서명 버전입니다. 개인 사용에는 문제없지만 플레이스토어 등록용은 아닙니다.
